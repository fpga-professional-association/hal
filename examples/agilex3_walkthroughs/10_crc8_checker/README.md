# 10 — serial CRC-8 checker

**Open [`guide.html`](guide.html) in a browser.** That is the walkthrough; this
file only says what is in the directory.

A complete, self-contained reverse-engineering exercise on a real Agilex 3
post-synthesis netlist: from a Quartus Prime Pro export back to RTL, with every
step shown as a command, the output it produced, and the reasoning that turns
that output into a conclusion.

| file | what it is |
| --- | --- |
| `spec.md` | the one-page specification the design implements |
| `design.v` | the original RTL — the answer key, not an input to the walk |
| `quartus/` | `build.tcl`, `crc8_checker.qsf`, `crc8_checker.qpf` — the project that was synthesised |
| `netlist/crc8_checker.vo` | the Quartus EDA netlist writer's export, verbatim |
| `netlist/netlist.hal.v` | the same netlist rewritten for HAL's Verilog parser (`tools/hal_agilex import`) |
| `netlist/netlist.anon.hal.v` | the same circuit with every design name stripped — **this is what the walk analyses** |
| `anonymize.py` | how that stripping is done, and exactly what it does not strip |
| `reference.py` | plain-Python model of `design.v`, used to check the export |
| `re_walk.py` | the walk itself: one subcommand per step |
| `check.py` | headless assertions over every claim the guide makes |
| `run_all.sh` | regenerates every image and artifact, in guide order |
| `recovered.v` | the RTL reconstructed from the netlist alone |
| `images/` | every picture in the guide (SVG, all generated by the commands shown) |
| `artifacts/` | findings documents, transcripts, DOT sources, the HTML findings report |

## Reproducing

Synthesis needs Quartus Prime Pro 26.1 and the Agilex 3 device support; the
analysis needs a built HAL and Graphviz. Inside the build container:

```bash
export HAL_BASE_PATH=/work/build HAL_PY_PATH=/work/build/lib
export PYTHONPATH=/work/build/lib
bash examples/agilex3_walkthroughs/10_crc8_checker/run_all.sh
```

`check.py` alone is the CI-sized smoke test.
