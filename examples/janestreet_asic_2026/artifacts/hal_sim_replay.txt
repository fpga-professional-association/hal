  A sky130 conb tie cell has no input pins, so hal_simulator never
  evaluates it -- a combinational gate is only evaluated when one of its
  input nets sees an event -- and GateLibrary::mark_gnd_gate_type /
  mark_vcc_gate_type reject a gate type with two output pins, so HAL does
  not give it a start value either.  Its constant 1 and 0 therefore stay X
  for the whole run.  This is a HAL finding, not a netlist one; see
  artifacts/hal_sim_issue_draft.md.
