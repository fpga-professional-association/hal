Detailed Description

Small string, number and stream helpers used throughout the simulator plugin.

The helpers replicate the semantics of the Qt calls that the plugin used before it was ported to the C++ standard library (QString::trimmed(), QString::split(), QString::toInt(&ok), QString::arg() with field width and base, QFile::readLine()). They are collected here so that the semantics are defined in exactly one place.
