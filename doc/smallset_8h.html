Detailed Description

Set of up to 256 small integers backed by AVX2, NEON, or plain 64-bit words.

The S-box canonical form search spends nearly all of its time in these sets, which is why there is one implementation per instruction set. smallset_portable_t is compiled on every platform and defines the semantics the vectorized backends have to reproduce, so the unit tests can diff whichever backend the machine selected against it. The header is internal to the plugin; every definition is TU-local so that no backend can leak across a binary boundary.
