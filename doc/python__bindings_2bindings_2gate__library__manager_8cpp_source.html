34  Load multiple gate libraries at once and combine them into a single composite gate library.
35 
36  A netlist in HAL is bound to exactly one gate library, so netlists that mix cells from several Liberty or HGL files
37  (standard cells, RAM macros, I/O pads, ...) need the libraries merged before instantiation. The files are loaded in
38  the given order, which gives the list search-path semantics: if two files define a gate type of the same name, the
39  one from the file that comes first wins and the other is discarded with a warning. Gate type IDs are re-assigned by
40  the composite library, so they do not match the IDs of the individual libraries.
41 
42  The composite library does not correspond to any file on disk, so netlists using it cannot be written to and read
43  back from a ``.hal`` file yet.
44 
45  :param list[pathlib.Path] file_paths: The ordered paths to the gate library files.
