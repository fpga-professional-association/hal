Many operations such as renaming waveform, creating groups, assigning waveform to groups require update of SALEAE directory. To avoid multiple write_json() calls during the same operation it is recommended to create an instance of SaleaeDirectoryStoreRequest rather than calling write_json() directly. When leaving the scope the destructor of the last instance will perform the write operation
 CSaleaeDirectoryFileIndexSingle SALEAE data file. The class comprises the index and header information from binary data file
 CSaleaeDirectoryNetEntryRegular waveform for a single simulated net. There is the possibility that no simulation data is available for the net (yet), so the number of associated binary files might be zero. The design allows to split the data into several files. This option however is currently not used. The ID must match the ID of the simulated net. The waveform name can be altered by user using the rename() method
 CSaleaeDirectoryComposedEntryComposed waveform. There are currently three types of composed waveforms: net groups, boolean combinations and trigger time sets which are all calculated from a set of regular waveform. Additional data like data or filter are dependend of the used type
